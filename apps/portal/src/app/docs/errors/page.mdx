# Errors

All errors share one envelope:

```json
{ "error": { "code": "INVALID_API_KEY", "message": "Invalid API key." } }
```

| HTTP status | Code | Meaning |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Request body failed validation |
| 400 | `PROVIDER_NOT_CONFIGURED` | No active credentials for this provider (LIVE keys only) |
| 401 | `INVALID_API_KEY` | Missing, malformed, or revoked API key |
| 403 | `MODE_NOT_ALLOWED` | e.g. calling a sandbox-only endpoint with a LIVE key |
| 404 | `PAYMENT_NOT_FOUND` | No payment with that id on this application |
| 429 | `RATE_LIMITED` | Too many requests — see `Retry-After` |
| 501 | `REFUND_NOT_SUPPORTED` | Refunds aren't available yet for this provider |

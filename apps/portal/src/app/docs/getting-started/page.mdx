# Getting started

AyitiPay gives you one API for both **MonCash** (Digicel) and **NatCash** (Natcom) mobile
money in Haiti. You bring your own merchant account for each provider; AyitiPay
normalizes the request/response shape and handles webhooks, retries, and sandboxing
for you.

## 1. Create an account and an application

Sign up in the [dashboard](/signup), then create an **application** — a container
for your API keys, connected provider credentials, and webhook endpoints.

## 2. Get a test API key

Every application starts with the ability to issue **TEST** keys immediately —
no real MonCash/NatCash credentials required. TEST keys always run against a safe,
built-in sandbox that never touches real money.

```bash
curl https://api.ayitipay.dev/v1/payments \
  -H "Authorization: Bearer pay_test_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "MONCASH",
    "amount": 500,
    "currency": "HTG",
    "reference": "order_123"
  }'
```

## 3. Go live

Once you're ready for real payments, connect your MonCash and/or NatCash merchant
credentials under **Providers** in the dashboard, then issue a **LIVE** key.
LIVE keys will return a clear `PROVIDER_NOT_CONFIGURED` error for any provider you
haven't connected yet.

Continue to [Authentication](/docs/authentication).

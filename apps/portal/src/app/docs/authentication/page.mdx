# Authentication

Every request to the public API is authenticated with an API key in the
`Authorization` header:

```bash
Authorization: Bearer pay_test_xxxxxxxxxxxxxxxxxxxx
```

Keys come in two modes:

- **`pay_test_...`** — always routed through the built-in sandbox. Safe to use freely.
- **`pay_live_...`** — routed to the real provider using your connected credentials.
  Requires an active provider connection under **Providers** in the dashboard.

Keys are shown in full only once, at creation time. AyitiPay stores only a
one-way hash — if you lose a key, revoke it and issue a new one.

## Rate limits

| Key mode | Limit |
|---|---|
| Test | 60 requests / minute |
| Live | 120 requests / minute |

A `429` response includes a `Retry-After` header.

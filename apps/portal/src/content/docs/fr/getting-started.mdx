# Prise en main

AyitiPay vous offre une seule API pour **MonCash** (Digicel) et **NatCash** (Natcom),
l'argent mobile en Haïti. Vous apportez votre propre compte marchand pour chaque
fournisseur ; AyitiPay normalise le format des requêtes et des réponses et gère pour vous
les webhooks, les nouvelles tentatives et le sandbox.

## 1. Créez un compte et une application

Inscrivez-vous dans le [tableau de bord](/signup), puis créez une **application** : un
conteneur pour vos clés d'API, vos identifiants de fournisseur connectés et vos endpoints
de webhook.

## 2. Obtenez une clé d'API de test

Chaque application peut émettre immédiatement des clés **TEST**, sans identifiants réels
MonCash/NatCash. Les clés TEST s'exécutent toujours dans un sandbox intégré et sécurisé
qui ne touche jamais à l'argent réel.

```bash
curl https://ayitipay-api-wishebee.vercel.app/v1/payments \
  -H "Authorization: Bearer pay_test_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "MONCASH",
    "amount": 500,
    "currency": "HTG",
    "reference": "order_123"
  }'
```

## 3. Passez en production

Quand vous êtes prêt pour les paiements réels, connectez vos identifiants marchands
MonCash et/ou NatCash dans **Fournisseurs** du tableau de bord, puis générez une clé
**PRODUCTION**. Les clés PRODUCTION renverront une erreur claire `PROVIDER_NOT_CONFIGURED`
pour tout fournisseur que vous n'avez pas encore connecté.

Continuez avec [Authentification](/docs/authentication).

# Authentification

Chaque requête vers l'API publique est authentifiée par une clé d'API dans l'en-tête
`Authorization` :

```bash
Authorization: Bearer pay_test_xxxxxxxxxxxxxxxxxxxx
```

Les clés existent en deux modes :

- **`pay_test_...`** : toujours acheminées vers le sandbox intégré. Utilisables librement.
- **`pay_live_...`** : acheminées vers le vrai fournisseur avec vos identifiants connectés.
  Elles nécessitent une connexion de fournisseur active dans **Fournisseurs** du tableau de bord.

Les clés ne sont affichées en entier qu'une seule fois, à leur création. AyitiPay ne
conserve qu'un hash irréversible : si vous perdez une clé, révoquez-la et générez-en une nouvelle.

## Limites de débit

| Mode de la clé | Limite |
|---|---|
| Test | 60 requêtes / minute |
| Production | 120 requêtes / minute |

Une réponse `429` inclut un en-tête `Retry-After`.

# Primeros pasos

AyitiPay te da una sola API para **MonCash** (Digicel) y **NatCash** (Natcom), el dinero
móvil de Haití. Tú traes tu propia cuenta de comercio de cada proveedor; AyitiPay
normaliza el formato de petición y respuesta y se encarga de los webhooks, los reintentos
y el sandbox por ti.

## 1. Crea una cuenta y una aplicación

Regístrate en el [panel](/signup) y crea una **aplicación**: un contenedor para tus
claves de API, las credenciales de proveedor conectadas y tus endpoints de webhook.

## 2. Obtén una clave de API de prueba

Cada aplicación puede emitir claves de **PRUEBA** de inmediato, sin necesitar
credenciales reales de MonCash/NatCash. Las claves de PRUEBA siempre se ejecutan en un
sandbox seguro e integrado que nunca toca dinero real.

```bash
curl https://ayitipay-api-wishebee.vercel.app/v1/payments \
  -H "Authorization: Bearer pay_test_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "MONCASH",
    "amount": 500,
    "currency": "HTG",
    "reference": "order_123"
  }'
```

## 3. Pasa a producción

Cuando estés listo para pagos reales, conecta tus credenciales de comercio de MonCash
y/o NatCash en **Proveedores** dentro del panel y luego genera una clave de **PRODUCCIÓN**.
Las claves de PRODUCCIÓN devolverán un error claro `PROVIDER_NOT_CONFIGURED` para
cualquier proveedor que aún no hayas conectado.

Continúa con [Autenticación](/docs/authentication).

# Webhooks

Registra un endpoint en **Webhooks** dentro del panel de tu aplicación. Cada vez que un
pago llega a un estado final, AyitiPay envía un evento por POST a todos los endpoints
activos de esa aplicación.

```json
{
  "id": "evt_...",
  "type": "payment.succeeded",
  "createdAt": "2026-09-21T12:00:05.000Z",
  "data": {
    "transaction": { "...": "misma forma que GET /v1/payments/:id" }
  }
}
```

## Verificar firmas

Cada entrega incluye un encabezado `X-Webhook-Signature`:

```
X-Webhook-Signature: t=1758470400,v1=5257a869...
```

Recalcula la firma sobre el cuerpo crudo de la petición con el secreto de tu endpoint
(se muestra en el panel) y compárala con una comparación de tiempo constante:

```js
const crypto = require("crypto");

function isValid(secret, rawBody, header) {
  const [tPart, vPart] = header.split(",");
  const timestamp = tPart.split("=")[1];
  const signature = vPart.split("=")[1];
  const expected = crypto
    .createHmac("sha256", secret)
    .update(`${timestamp}.${rawBody}`)
    .digest("hex");
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature));
}
```

## Reintentos

Las entregas fallidas (respuesta distinta de 2xx o tiempo agotado) se reintentan con
espera progresiva, hasta 6 intentos, tras los cuales la entrega se marca como
`EXHAUSTED`. La primera entrega se envía de inmediato al cambiar el estado del pago; los
reintentos se procesan una vez al día. Puedes reenviar manualmente cualquier entrega
desde el panel.

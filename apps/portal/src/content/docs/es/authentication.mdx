# Autenticación

Cada petición a la API pública se autentica con una clave de API en el encabezado
`Authorization`:

```bash
Authorization: Bearer pay_test_xxxxxxxxxxxxxxxxxxxx
```

Las claves tienen dos modos:

- **`pay_test_...`**: siempre se enrutan al sandbox integrado. Puedes usarlas libremente.
- **`pay_live_...`**: se enrutan al proveedor real con tus credenciales conectadas.
  Requieren una conexión de proveedor activa en **Proveedores** dentro del panel.

Las claves se muestran completas solo una vez, al crearlas. AyitiPay guarda únicamente un
hash irreversible: si pierdes una clave, revócala y genera una nueva.

## Límites de uso

| Modo de la clave | Límite |
|---|---|
| Prueba | 60 peticiones / minuto |
| Producción | 120 peticiones / minuto |

Una respuesta `429` incluye un encabezado `Retry-After`.
